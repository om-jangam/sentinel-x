# Archive · Initial design, July 2026

These documents describe Sentinel-X as it was first framed: an "autonomous AI security operations
platform" with a multi-agent supervisor, risk-based alerting as the primary alerting model,
human-approved containment actions, and a six-store architecture.

That framing is **superseded** by
[ADR-0014](../../adr/ADR-0014-lock-scope-security-investigation.md): Sentinel-X is a security
investigation and attack-chain reconstruction platform, and endpoint security belongs to Aegis.

They are kept, unedited, for the reasoning history. Nothing here describes the current product.

| `13-interview-value.md` | Portfolio and interview framing | Pitches the superseded product |
